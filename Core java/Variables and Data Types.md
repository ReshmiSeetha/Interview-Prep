Variables
    We have to work with data in our program. 
    We may accept the data from user or we want to store tha data in our program.
    Data will be stored in the DB.
    So when need to process the data or when we receive the data where will we store it?
    We will store it in the memory.
    So we need a container to store the data in the memory.
    That container is called as a variable.
        We will store the data in the variable.
        We will give a name to the place where the we store the data.
        We can store number , text , decimal , boolean value in the variable.
