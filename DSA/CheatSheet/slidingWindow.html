DSA Interview Cheat Sheet

Sliding Window

Use when you need a contiguous subarray or substring and want to avoid recomputing from scratch. Keep a moving window, expand and shrink based on constraints.

Time: O(n) Space: O(1) / O(k) Contiguous range Expand + shrink Two pointers

What it is

  • A technique for subarrays / substrings.
  • Maintain a window with two pointers.
  • Update state incrementally instead of recomputing.

Core idea

Expand right → Check constraint → Shrink left → Record answer

Use it for

  • Longest / shortest subarray or substring
  • At most K distinct
  • Sum / average / frequency constraints
  • Fixed-size window problems

Types

Fixed window
Window size stays constant
Variable window
Grow/shrink based on condition

State to track

  • Counts / frequency map
  • Running sum
  • Number of distinct elements
  • Maximum / minimum in window

Common problems

  • Maximum sum subarray of size K
  • Longest substring without repeating characters
  • Longest substring with at most K distinct characters
  • Minimum window substring
  • Subarray Product Less Than K

Java essentials

int left = 0;
for (int right = 0; right < n; right++) {
    // add nums[right]
    while (invalid) {
        // remove nums[left]
        left++;
    }
    // update answer
}

When to recognize it

  • Problem mentions contiguous subarray or substring.
  • Brute force repeats work for overlapping ranges.
  • You can maintain the answer by adding/removing one element.
  • Constraints ask for O(n) or better.

Pitfalls

  • Forgetting to shrink until valid.
  • Mixing fixed and variable window logic.
  • Not updating counts when moving left.
  • Assuming it works for non-contiguous subsequences.

Quick rule

If the problem asks about a contiguous range and
you can update the answer by adding/removing one element,
think Sliding Window.
