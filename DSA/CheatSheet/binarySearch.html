DSA Interview Cheat Sheet

Binary Search

Use when the search space is sorted or when a condition changes monotonically. Think in terms of halves, boundaries, and first true / last false.

Time: O(log n) Space: O(1) Sorted / Monotonic Half elimination First true / last false

What it is

  • A divide-and-conquer search technique.
  • Eliminates half of the search space each step.
  • Works on indices, values, or answer space.

Core idea

Pick mid → Check condition → Move left / right → Stop at boundary

Use it for

  • Sorted array search
  • Lower bound / upper bound
  • First / last occurrence
  • Binary search on answer
  • Monotonic feasibility problems

Types

Exact search
Find target in sorted data
Boundary search
First true / last false
Lower bound
First index >= target
Answer search
Find minimum feasible value

State to track

  • Low / high pointers
  • Mid value
  • Predicate result: valid or invalid
  • Best answer so far when searching answer space

Recognition clues

  • Sorted array or sorted matrix.
  • Problem asks for first, last, minimum, maximum, or position.
  • Condition becomes true only after a point.
  • You can rule out half the space every check.

Java essentials

int low = 0, high = n - 1;
while (low <= high) {
    int mid = low + (high - low) / 2;

    if (arr[mid] == target) return mid;
    else if (arr[mid] < target) low = mid + 1;
    else high = mid - 1;
}

Answer search template

int low = minPossible, high = maxPossible;
int ans = -1;

while (low <= high) {
    int mid = low + (high - low) / 2;

    if (isValid(mid)) {
        ans = mid;
        high = mid - 1;
    } else {
        low = mid + 1;
    }
}

Pitfalls

  • Wrong boundary update.
  • Using binary search without monotonicity.
  • Overflow in mid calculation.
  • Confusing exact search with lower bound.

Common problems

  • Search in sorted array
  • First and last occurrence
  • Search insert position
  • Peak element
  • Search in rotated sorted array
  • Koko Eating Bananas
  • Split Array Largest Sum
  • Capacity To Ship Packages Within D Days
  • Kth Smallest Element in a Sorted Matrix
  • Median of Two Sorted Arrays

Quick rule

If the array is sorted or the answer space is monotonic,
and every check lets you eliminate half the search space,
think Binary Search.
